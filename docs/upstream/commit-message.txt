drm/fl2000: Add driver for Fresco Logic FL2000 USB display adapters

The Fresco Logic FL2000DX is a USB 3.0 display controller used in
inexpensive USB to VGA and USB to HDMI adapters (USB ID 1d5c:2000). The
FL2000 itself outputs parallel RGB/VGA; HDMI adapters pair it with an
ITE IT66121 HDMI transmitter that sits on the FL2000's I2C bus.

The driver consists of:

- a USB driver that waits for the three FL2000 interfaces and then
  registers a component master
- a regmap for the FL2000 registers, accessed with vendor control
  transfers, and an I2C adapter on top of the FL2000 I2C engine
- a DRM device with GEM SHMEM buffers. Frames are converted from
  XRGB8888 to RGB888 or RGB565, depending on the USB bandwidth the mode
  needs, and sent as one bulk transfer per frame; the previous frame is
  resent when there is no new one
- PLL and timing programming for the requested mode
- an IT66121 bridge instantiated on the FL2000 I2C bus. EDID is read
  through the IT66121 DDC engine and, where the monitor's DDC lines are
  wired to the FL2000 instead (as on the tested adapter and the Fresco
  reference design), directly over the FL2000 I2C bus

Tested on x86_64 with a UGREEN USB 3.0 to HDMI adapter (FL2000DX +
IT66121FN) and a 1920x1080 monitor: EDID, mode setting and a GNOME
Wayland desktop work.

The driver is based on the out-of-tree fl2000_drm driver by Artem
Mygaiev, which carries code from the Fresco Logic reference driver.
