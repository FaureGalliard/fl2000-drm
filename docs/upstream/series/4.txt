drm/fl2000: Add KMS display pipeline

Register the DRM device once all FL2000 interfaces are bound and the
IT66121 component is available, and connect the pieces:

- a single plane/CRTC/encoder pipeline with GEM SHMEM framebuffers and
  XRGB8888 as the only format. The framebuffer is only read by the CPU,
  so it does not need to be physically contiguous
- mode validation and PLL/timing programming for the requested mode
- the FL2000 interrupt endpoint, which reports monitor and IT66121
  events and triggers a hotplug event

Tested on x86_64 with a UGREEN USB 3.0 to HDMI adapter (FL2000DX +
IT66121FN) and a 1920x1080 monitor: EDID, mode setting and a GNOME
Wayland desktop work.
